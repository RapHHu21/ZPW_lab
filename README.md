# ZPW_lab

Prosta gra **Minesweeper (Saper)** stworzona w HTML, CSS i JavaScript.

Projekt realizowany w ramach przedmiotu **Zarządzanie projektem wdrożeniowym**.

## Cel projektu

Celem projektu jest praktyczne wykorzystanie systemu kontroli wersji Git i platformy GitHub oraz narzędzia Jira do planowania zadań, organizacji pracy i współpracy zespołowej.

## Technologie

- HTML — struktura strony
- CSS — wygląd interfejsu
- JavaScript — logika gry
- Git i GitHub — wersjonowanie kodu i współpraca
- Jira — zarządzanie zadaniami

## Uruchomienie

1. Pobierz lub sklonuj repozytorium.
2. Otwórz plik `main.html` w przeglądarce.

## Funkcjonalności

- Plansza 6 × 6 z 6 losowo rozmieszczonymi minami.
- Odkrywanie pól poprzez kliknięcie.
- Wyświetlanie liczby sąsiadujących min.
- Wykrywanie wygranej i przegranej.
- Możliwość rozpoczęcia nowej gry.
